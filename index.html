MomentDrop Publisher is a desktop application that helps users prepare and publish user-selected video content to supported social media platforms from one streamlined workflow.

What is MomentDrop?

MomentDrop Publisher provides tools for preparing video posts, generating and editing publishing metadata, selecting connected social media accounts, and publishing content chosen by the user.

How it works

1. Select

The user selects a video from their computer that they want to prepare for publishing.

2. Prepare

MomentDrop helps prepare titles, descriptions, hashtags and other publishing metadata. The user can review and edit the information before publishing.

3. Choose

The user chooses which connected social media accounts should receive the video.

4. Publish

Content is published only after the user explicitly initiates the publishing action.

Supported platforms

MomentDrop Publisher is designed to work with supported social media publishing integrations, including TikTok, YouTube and Instagram where the required platform permissions are available.

User control

Users maintain control over the videos they select, the metadata associated with their posts, the destination accounts and the final publishing action.
